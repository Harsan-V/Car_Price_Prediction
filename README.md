# Car Price Prediction:
This Project Demonstrates to Predict The price of an Used Car available in the Market. It uses random Forest Model to predict the amount with Test accuracy of 93% and Training Accuracy of 93%. Used FASTAPI for seamless interaction between the application.

# How To Run:

install these libraries --> 
fastapi
uvicorn
pandas
scikit-learn
joblib

After Installing go to terminal and type : uvicorm day45:app --reload
This ensures that the FastApi Runs on a uvicorn server.
Then Open /docs from the url to see the fastapi documentation. You can Check If the Endpoints are working or not.
Then if The Requests Working Correctly U can go the url and change /docs to /ui to run the app.
